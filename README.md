# 百日安全奖校核小工具

本机浏览器打开的单页校核工具，用于汇总各单位百日安全奖申报表、按「姓名 + 身份证号」去重、核对岗位系数/奖励基数异常，并与上期申报对比（新增、离职/调出、岗位或系数变化）。

数据只在浏览器本地处理，不会上传服务器。可离线使用，也可挂到 EdgeOne / 任意静态站点。

## 文件说明

| 路径 | 说明 |
|------|------|
| `index.html` | **主程序（单文件）**，已内联 SheetJS，双击或用浏览器打开即可 |
| `samples/本期样例.csv` | 虚构本期数据（含跨单位重复、系数/基数异常、本期新增等） |
| `samples/上期样例.csv` | 虚构上期数据（含本期已离职人员、岗位/系数变化对照） |
| `vendor/xlsx.full.min.js` | SheetJS 备用副本；当前 `index.html` 已内联，一般不用单独带 |
| `source.txt` 等 | 申报依据材料（开发参考，与运行无关） |

> 若以后改为「HTML + 外链库」拆分版：请把 `vendor/` 与 `index.html` 放在同一目录，并用相对路径引用 `vendor/xlsx.full.min.js`。离线拷贝时务必带上 `vendor`。

## 用法

1. 用 Chrome / Edge / 麒麟自带浏览器打开 `index.html`（也可 `file://` 离线打开）。
2. **本期申报表**：可多选多个单位的 CSV / XLSX，自动汇总并保留「来源」文件名。
3. **上期申报表**（可选）：选一份上期汇总或代表表，用于对比。
4. 检查「列映射」：工具会按表头自动猜测，不对可手动改。**姓名、身份证号必填映射**。
5. 点「开始校核」，在四个页签查看结果，并可导出 UTF-8 BOM CSV（Excel 可直接打开中文）。

调试时可点 **「载入内置样例」**，无需选文件即可跑通全流程。

### 用样例 CSV 验证

1. 本期选择 `samples/本期样例.csv`，上期选择 `samples/上期样例.csv`。
2. 开始校核后预期大致为：
   - **汇总**：约 13 行有效数据；「张三」标记为重复。
   - **重复**：张三（身份证 `110101199001011234`）出现在「本部综合部」与「第二物业中心」→ 跨单位重复。
   - **疑似错误**：孙八（奖励基数 `abc`）、周九（岗位系数为空）。
   - **上期对比**：
     - 本期新增：冯十二
     - 离职/调出：卫十五
     - 岗位或系数变化：吴十（系数 1.0→1.05）、郑十一（岗位 工程员→工程主管）

## 字段与规则

### 常用列（可映射）

- 单位、姓名、身份证号、岗位、岗位系数、奖励基数、备注

### 去重键

`姓名 + 身份证号`（去空白；身份证号转大写）。重名但身份证不同视为不同人。

### 校核规则

1. **汇总**：合并本期所有文件行，保留来源；重复人员在汇总中标出。
2. **重复**：同一去重键出现多于 1 次（跨单位或同批多文件）。
3. **疑似错误**：姓名/身份证为空；已映射的岗位系数或奖励基数为空或非数字。
4. **上期对比**（需载入上期）：
   - 本期有、上期无 → 本期新增
   - 上期有、本期无 → 离职/调出
   - 两边都有但岗位或系数不同 → 岗位或系数变化

## 挂到 EdgeOne / 静态站点

1. 将 `index.html`（单文件即可）上传到对象存储或 Pages，开启静态网站。
2. 绑定你的域名；HTTPS 下同样只在用户浏览器本地算数。
3. **不要**把含真实人员身份证号的申报表放进公开 Git 仓库或公开站点目录。样例仅为虚构数据。

## 敏感数据提醒

- 真实申报表含身份证号等个人信息，请仅在内网或本机使用。
- 公开 GitHub 仓库请只提交本工具与虚构样例，**勿提交真实业务表**。
- 导出的校核结果同样敏感，注意存放与传阅范围。

## 技术说明

- CSV：自研解析，不依赖库。
- Excel（.xlsx）：使用 SheetJS（xlsx），当前已内联进 `index.html`（约 0.88 MB）。
- 无后端、无构建步骤；麒麟等国产系统用浏览器即可打开。
